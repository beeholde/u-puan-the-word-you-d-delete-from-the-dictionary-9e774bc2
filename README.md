One word you'd erase from the dictionary forever: **gone**. Delete "gone" and it is gone — the word performs its own deletion, so the joke lands the instant it is read. None of the 702 entries received so far picked it; the crowded picks are irregardless, queue, moist, literally and defenestration. The program writes exactly that one word (4 bytes, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validated as a single lowercase word within the sealed gate's 1–77 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
